# Security Policy

## Supported Versions

Security updates are provided for the following versions of `changelog-guard`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within `changelog-guard`, please report it responsibly:

1. Do NOT open a public issue on GitHub.
2. Report vulnerabilities via GitHub Private Vulnerability Reporting at:
   https://github.com/YusufBeratZengin/changelog-guard/security/advisories/new
3. Provide detailed steps to reproduce the vulnerability, including environment details and any potential exploit scenario.

You will receive an acknowledgment within 48 hours, followed by regular status updates until a patch is issued.
